## A little about me

I’m a curious builder who enjoys turning tangled problems into calm, understandable experiences. I care about the small things that make software feel good: clear interfaces, sensible defaults, and code that the next person can follow.

These days, I’m exploring the space where **frontend craft**, **reliable APIs**, and **practical automation** meet. I like learning in public, shipping in small increments, and keeping a healthy curiosity for what I haven’t tried yet.

## Small ideas I’d like to make real

- **Pocket Atlas** — a lightweight place to collect and revisit useful links, with thoughtful search and tagging.
- **Quiet Queue** — a tiny task inbox designed to make the next action obvious, not overwhelming.
- **Readable API Notes** — a documentation companion that turns endpoint details into examples people can actually use.

These are concept sketches, not shipped-project claims; I’m interested in making the useful version of one of them next.
